# Tennis Analysis

تحلیل داده‌های مسابقات تنیس، شامل ۲۷ سؤال، خروجی‌های CSV و نمودارهای قابل ارائه.

## ساختار پروژه

- `notebooks/` — نوت‌بوک اصلی تحلیل
- `data/input/` — داده‌های ورودی و لایه‌های پاک‌سازی‌شده
- `data/output/` — نتایج محاسباتی سؤالات
- `figures/` — نمودارهای PNG و SVG

## اجرا

```bash
pip install -r requirements.txt
```

سپس نوت‌بوک موجود در پوشهٔ `notebooks` را از ابتدا اجرا کنید.
